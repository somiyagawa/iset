# ISET — International Seminar / Symposium of Egyptology in Tokyo

東京国際エジプト学セミナー／シンポジウム（ISET）

This repository holds the ISET event websites. Each event is a single, self-contained
HTML file — no build step, no dependencies beyond web fonts.

## Events

### Seminar — Prof. Jean Winand (3 November 2026)

**エジプトの諸文字は、エジプト語の表記にどこまで適していたのか**
*How well adapted were the Egyptian writings for transcribing Egyptian?*

- **Speaker:** Prof. Jean Winand (University of Liège, Belgium)
- **Date:** 3 November 2026 (Tuesday, Culture Day), 13:30–18:00 JST
- **Venue:** Lecture Hall No. 1 (2F), Faculty of Law & Letters Building 2,
  Hongo Campus, The University of Tokyo
- **Language:** English
- **Registration:** https://forms.gle/96g5YcpCAmvWZYcT7
- **Page:** `winand.html`

## Viewing

Open `index.html` in any modern browser.

## Hosting on GitHub Pages

After pushing this repository, enable **Settings → Pages → Source: `main` / root**.
The site will be served at `https://<your-username>.github.io/iset/` — the
top page at the root, the seminar at `.../iset/winand.html` and the symposium at `.../iset/iset2026.html`.
